## How the project was run (so the new account can do the same)

- One lead session (Fable or Opus) writes specs in `docs/specs/<phase>.md`, spawns cloud
  sessions per phase (each a lead with dsp-engineer / match-engineer / reviewer subagents,
  Sonnet), and an **integration-lead** session that merges accepted branches into the working
  branch with full validation (gcc + clang -Werror + ctest + pluginval) and pushes.
- Every phase ends with `<phase>_REPORT.md` recording the reviewer verdict; nothing merges
  without ACCEPT.
- Usage: the 5-hour cap trips with ~5 cloud sessions + local agents running; keep ≤4 cloud
  + ≤3 local and pause the lowest priority at `allowed_warning`. Sessions resume from on-disk
  state after a cutoff.

## Decisions worth remembering

- Any heavy tone, not Gatecreeper-only; chainsaw = a *family* of circuits (HM-2, HM-2W
  custom, modded (Wurm/Torcher/Wrath), Eyemaster, big fuzz) — Zone/Rat are not chainsaw.
- Matcher: stem reference basis, HF texture term, Occam (single path unless blend buys
  ≥0.1 dB), level-matched blends (10.1), `--quick` = preview, `--thorough` = final.
- Play-along backing: use the original record when a single linear time-map fits within
  ±30 ms (Bolt Thrower: 0.8 % stretch), else the cover's own stems (Nails).
- Exports: no gate/time-FX/long comp trained in; shared cab → no-cab export exact; `-nc`
  marking; personal use only.
